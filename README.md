# narabee

Firefox の 1 つのタブに、2〜4 つのサイトを並べて表示する拡張機能。

- レイアウトは 16 通り: 1 つ / 左右・上下に 2 つ / 横・縦に 3 つ / 左 1・右 2 などの 2-1 型 /
  横・縦に 4 つ / 2×2 / 左 1・右 3 / 上 1・下 3 /
  互い違い (左の列は上が大きく右の列は下が大きい 4 枠と、その横向き)
- **埋め込みを拒否しているサイト** (`X-Frame-Options` や CSP の `frame-ancestors`) も並べられる
- 普段の Firefox のログイン状態がそのまま使える (クッキーは普通のタブと共通)
- 境目はドラッグで動かせる。比率はレイアウトごとに覚える
- 枠ごとに URL 欄・戻る・進む・再読み込み・拡大縮小 (−/+ で 30〜200% の段階)・新しいタブで開く・閉じる (× で空に戻す)
- 見出しの倍率 (「100%」) を押すと、倍率を手で入れるダイアログが開く (10〜500%)。
  「セット」か Enter で反映、「リセット」で 100%。× ・Esc・ダイアログの外を押すと、入力を捨てて閉じる
- 枠ごとに自動で再読み込みできる (⏱ を押して分と秒で間隔を指定。「更新なし」で止める)。
  間隔は枠ごとに覚え、Firefox を終了しても残る
- 枠の見出しの左上の番号 (①〜④) を別の枠へドラッグ & ドロップすると、落とした側で動きが変わる
  (ドラッグ中、落とす先の枠に左右どちらが何をするかが出る):
  - **左半分: 入れ替え。** 2 つの枠の場所を入れ替える。ページは読み込み直さないので、ログイン後の画面や
    動画もそのまま移る。倍率と自動の再読み込みもページと一緒に移る
  - **右半分: コピー。** 落とした先の枠に同じ URL を開く (倍率や自動の再読み込みは落とした先の枠のまま)
- 番号 (①〜④) は場所に付く。左上はいつも ①。「枠に送る」の枠 N もこの番号
- 枠の見出しをダブルクリック (または ⛶) で、その枠だけを大きくする / 戻す
- レイアウトを切り替えても、枠の中のページは読み込み直されない
- タブ (ウィンドウ) の題名は「narabee(枠 1 のページの題名)」。枠 1 が空なら「narabee」
- 次に開いたとき (narabee のタブを再読み込みしたときも) は、前回の URL・スクロール位置・
  レイアウト・比率・倍率で始まる

## 使い方

1. ツールバーの narabee のボタンを押すと、narabee のタブが開く。
   - そのウィンドウに narabee のタブがあれば、narabee のタブを 1 つ足す (1 つのウィンドウに幾つでも開ける)。
   - 無ければ、閉じた narabee のタブを復元する (複数あればすべて)。復元するものが無ければ新しく開く。
   - 復元の対象は、どのウィンドウにも開いていない、枠に何か入っていた narabee。枠が全部空のまま閉じたものは捨てる。
   narabee のタブごとに、枠の URL・レイアウト・比率・スクロール位置を別々に覚える。
2. 上の帯でレイアウトを選ぶ。

上の帯 (レイアウトのボタンが並ぶ行) は普段は隠れている。ツールバーのボタンで narabee のタブを
足した (復元した) ときと、narabee のタブを右クリック →「narabee レイアウトバーを表示」で出て、
レイアウトを選ぶ・帯の右端の × を押す・15 秒たつ (帯の上にマウスがある間は数えない) のどれかで隠れる。
narabee のタブを再読み込みしたときや、Firefox を起動し直してタブが戻ったときは出ない。
3. 各枠の URL 欄に URL を入れて Enter。URL でない文字は Google で検索する。

### 自動で再読み込み

枠の見出しの ⏱ を押すと、間隔を分と秒で入れるダイアログが開く (分は 0〜1440、秒は 0〜59)。
「セット」か Enter で始まり、見出しに間隔が出る (例: ⏱10秒、⏱23分、⏱1分30秒)。
「更新なし」か 0 分 0 秒で止まる。間隔は narabee のタブの枠ごとに別々で、Firefox を終了しても覚えている。

- 次の再読み込みまでの時間は、ページの読み込みが終わったところから数える
  (枠の中でリンクを押して別のページに移ったときも、そこから数え直す)。
- 次のときは、その回は読み直さずに次の回へ回す: 枠の中の入力欄で文字を打っているとき
  (焦点があるとき)、読み込みの途中のとき。
- 間隔のダイアログを開いている間は、どの枠も自動では読み直さない。閉じたとき、その間に
  時刻が来た枠をすぐ読み直す (間隔を変えた枠は、新しい間隔で数え直す)。
- フォームを送信した結果のページ (POST) は読み直さない。読み直すと送信をもう一度行うことになり、
  Firefox が確認を出すため。見出しの間隔に取り消し線が付き、別のページに移ると再開する。
- 枠を × で閉じると、その枠の自動の再読み込みもやめる。

普通のタブで右クリック →「このページを narabee の枠に送る」→「枠 N」でも入れられる
(そのウィンドウで最後に使っていた narabee に送る。無ければそのウィンドウに開く)。
リンクの上で右クリックすると「リンクを narabee の枠で開く」になる。
送り先の枠が今のレイアウトで隠れているときは、その枠が見えるレイアウトに切り替わる。

## インストール

[Releases](https://github.com/iosxi/narabee/releases) から `narabee-<版>-signed.xpi` を
ダウンロードし、Firefox の窓にドラッグ & ドロップする (または `about:addons` の歯車 →
「ファイルからアドオンをインストール」)。

## 注意

- narabee のタブの中に読み込むときに限り、サイトの「埋め込み禁止」の指示を取り除く。
  普通のタブで開いたページには何もしない。
- 枠の中のページが「タブ全体を移動」しようとしたとき (`target="_top"` のリンクや
  フォーム、`top.location` を使うスクリプト) は、その枠の中で開く。楽天証券の会員ページは
  画面の切り替え (ログイン、メニュー) にこれを使う。今と同じ URL へ移ろうとするだけのもの (枠から抜け出す処理) は無視する。
- YouTube のライブのチャット欄の × で、欄が畳まれる (v14 までは畳まれなかった)。メンバーシップの購入など、
  チャット欄から動画のページへの合図も届く。
- Service Worker を持つサイト (YouTube など) も並べられる。ただし Service Worker が
  ネットに取りに行かず、自分の保存分から返すサイトは並べられない。
- パスキーでのログイン (WebAuthn) を枠の中で使えるようにしてある。
- Google のログイン画面は枠の中では受け付けられない (Google が 401 を返す)。
  枠の中でログインを押すと、ログイン画面だけ普通の新しいタブで開く。ログインが済んで
  元のサイトに戻ると、そのタブは自動で閉じ、ログイン後のページが枠に読み込まれる。
- 自分が埋め込まれていることを検知して、表示をやめるサイトは並べられない。
- Firefox 142 以降。
